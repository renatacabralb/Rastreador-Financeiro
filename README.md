# Rastreador de Gastos
 
App pra controle financeiro pessoal que adivinha a categoria dos seus gastos e aprende com as suas correções.
 
##  O que ele faz

- **Lançamento de gastos:** Cadastre valor, descrição, data e forma de pagamento.

- **Categorização automática:** Sugere se o gasto é Alimentação, Lazer, Transporte, etc., analisando a descrição.

- **Modo de aprendizado:** Se você corrigir uma categoria sugerida, o app guarda essa regra e não erra nas próximas.

- **Dashboard:** Visão geral das suas despesas com gráficos por categoria e mês.

- **Metas e limites:** Alerta visual quando você passa do limite do seu orçamento.
 
##  Tecnologias

- **Front-end:** React.js

- **Back-end & Banco:** Supabase (PostgreSQL)

- **Testes:** Jest

- **CI/CD:** CircleCI
